# 🎨 Viral Image Generator - Vercel Edition

A web-based image generator for creating viral content, optimized for Vercel deployment.

## Features

- 🔥 **Viral Content**: Hugot quotes, motivation, riddles
- 📱 **Multiple Formats**: Instagram, Facebook, Twitter
- ⚡ **Instant Generation**: No file system dependencies
- 🌐 **Cloud Ready**: Optimized for Vercel serverless

## Deploy to Vercel

1. **Fork/Clone this repo to GitHub**
2. **Connect to Vercel:**
   - Go to [vercel.com](https://vercel.com)
   - Import your GitHub repository
   - Deploy automatically!

3. **Environment**: No environment variables needed

## Local Development

```bash
# Install dependencies
pip install -r requirements.txt

# Run locally (Python 3.9+)
python -m http.server 8000
```

## API Endpoints

- `POST /api/generate` - Generate viral images
  ```json
  {
    "type": "hugot_tagalog|hugot_english|motivation",
    "format": "instagram_post|facebook_post|twitter_post"
  }
  ```

## Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Python 3.9, Vercel Serverless Functions
- **Image Processing**: Pillow (PIL)
- **Hosting**: Vercel (Free tier)
